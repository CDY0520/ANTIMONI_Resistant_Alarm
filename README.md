# 자연어처리 기반 검사 판독문 분석을 통한 감염병 모니터링 서비스 개발  
기간: 2025. 06. 27 ~ 2025. 07. 31 (총 5주)  
팀 구성: 5명  
담당 역할(개인 기여 기준): 데이터 수집·전처리(80%), 예측모델 적용 및 성능 검증(50%), 경보 로직 설계(50%), Streamlit 정보 대시보드(100%)  

---

# 핵심기여
모델 학습이 가능하도록 데이터셋 구조 설계  
내부·외부 이상치 탐지 기반 5단계 경보 로직 구현  
예측·이상치 탐지 분석 결과 Streamlit 기반 대시보드 시각화  

---

# 주요목표
비정형 검사 판독문을 구조화하여 감염병 발생 추이·이상 신호를 모니터링하는 시스템 구축  

---

# 배경 및 문제 정의
*비정형 검사 결과를 ‘보고’가 아닌 ‘지속 판단‘이 가능한 구조로 전환*  

기존 데이터 구조의 한계:  
비정형 판독문 중심 → 즉시 비교·판단 어려움  
발생 추이·이상기준 부재 → 사후 분석에 그침  
  
운영 관점의 문제:  
내부 확산·외부 유입 구분 불가  
감염 환자 격리 조치 등 수직적이고 단일 결과 중심 대응  
  
프로젝트 접근 방향:  
검사 데이터를 정형·시계열 구조로 재설계  
내부·외부 지표를 통합한 감염 모니터링 체계 구축  

---

# 주요 성과  
단계 예측 기반 CRE 발생 건수 예측 모델 구축  
평균 MAPE 5.4% 달성 → 운영 기준(10%) 내 안정적 예측 성능 확보  
예측–이상치–경보–대시보드까지 실제 운영 흐름을 고려한 서비스 설계
